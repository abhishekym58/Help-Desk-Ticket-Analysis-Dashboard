# Help Desk Ticket Analysis & Dashboard 📊

## 📌 Project Overview
This project is an interactive IT Service Management (ITSM) dashboard built entirely in Microsoft Excel. It analyzes a dataset of 200 simulated help desk tickets to track support performance, identify recurring IT issues, and monitor Service Level Agreement (SLA) compliance. 

The goal of this project is to demonstrate a clear understanding of the ticketing lifecycle, escalation procedures, and how help desk efficiency is measured in an enterprise IT environment.

## 🛠️ Tools Used
* **Microsoft Excel:** Data cleaning, formatting, and dataset structuring.
* **Pivot Tables & Pivot Charts:** Aggregating data by department, issue type, and escalation level.
* **Excel Dashboarding:** Implementing dynamic slicers and KPI tracking.

## 📈 Key Metrics Tracked
* **Total Ticket Volume:** Categorized by departments (Admin, Finance, HR, IT).
* **SLA Breach Rate:** Monitored compliance, highlighting an overall breach rate of 42.50%.
* **Average Resolution Time:** Tracked operational efficiency (Average: 8.76 hours).
* **Customer Satisfaction (CSAT):** Evaluated end-user feedback (Average score: 3.05).
* **Issue Categorization:** Segmented tickets by root cause (e.g., System Crash, Software Install, Network Issues, Access Requests).

## 🚀 Features
* **Interactive Filtering:** Slicers for Department, Ticket Status, Assigned Agent, and Priority allow for real-time data drill-downs.
* **Escalation Tracking:** Visualized the correlation between ticket priority and the required escalation level (Level 1, Level 2, Level 3).

## 💡 What I Learned
Building this dashboard strengthened my understanding of ITSM workflows. It highlighted the importance of accurate ticket categorization, prioritizing high-impact network/system crashes, and the direct impact that prompt resolution times have on customer satisfaction and SLA compliance.
